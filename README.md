# Критическая опора

2D-физическая головоломка про контролируемый демонтаж. Игрок бьёт по опорам водонапорной башни, добиваясь обрушения верхних секций, не разрушив генератор и не завалив красную зону.

Работает в браузере на Canvas2D, вся графика и звук генерируются кодом — внешних ассетов нет.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
npm run verify   # формат, линтер, типы, тесты, сборка
npm run playthrough   # детерминированный прогон уровня без браузера
```

## Управление

| Действие           | Ввод                               |
| ------------------ | ---------------------------------- |
| Прицеливание       | перетаскивание мышью или удержание |
| Выстрел            | отпускание                         |

| Пауза              | `Esc`                              |
| Замедление времени | `Space` (удержание)                |
| Траектория         | `T`                                |
| Анализ конструкции | `V`                                |
| Отладочный оверлей | `F1`                               |

## Цель уровня

`water_tower_01` даёт три запуска. Победа засчитывается, когда одновременно:

- разрушено не менее 80% элементов группы `upper_tower`;
- урон генератору `generator_01` не превышает 25%;
- масса крупных обломков в красной зоне не превышает 320 кг.

Эталонный план — два выстрела под 58° на мощности 0.56 — приводит к победе со счётом 2666 (ранг Perfect Demolition). Он же зафиксирован в интеграционном тесте, поэтому случайная правка баланса ломает сборку, а не игру.

## Архитектура

Игровая логика не знает о DOM: `GameSession` работает с физикой, целями и счётом и выдаёт снимки состояния. Рендер, ввод, UI и звук подключаются снаружи, поэтому один и тот же уровень воспроизводится и в браузере, и в headless-режиме на `@napi-rs/canvas`.

```text
src/
  core/       EventBus, GameStateManager, InputController, SaveManager, MathUtils
  data/       схемы уровней, материалы, снаряды, цели
  physics/    planck-мир, баллистика, снаряды, разрушение конструкции
  gameplay/   GameSession, цели, зоны, обломки, счёт, анализ
  render/     SceneRenderer, камера, эффекты, траектория, debug-оверлей
  ui/         отрисовка интерфейса и контроллеры
  audio/      процедурный синтез через WebAudio
  levels/     реестр уровней и JSON-файлы
```

Подробности: [docs/architecture.md](docs/architecture.md), [docs/level-authoring.md](docs/level-authoring.md).
