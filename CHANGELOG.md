# Changelog

## 0.1.0

Первый играбельный прототип.

- Игровой цикл на `planck`: баллистика, попадания, разрушение конструкции по энергии удара, цепные реакции критических опор.
- Уровень `water_tower_01`: три запуска, цель «обрушить 80% верхней башни», защита генератора, красная и зелёная зоны.
- Процедурные рендер и звук на Canvas2D и WebAudio, внешних ассетов нет.
- Энергетическая модель урона с коэффициентом затухания в цепных реакциях.
- Сохранение настроек и рекордов с миграцией повреждённых данных.
- Headless-прогон `npm run playthrough` и интеграционный тест эталонного плана победы.
- Документация: `README.md`, `docs/architecture.md`, `docs/level-authoring.md`, `AGENTS.md`.
